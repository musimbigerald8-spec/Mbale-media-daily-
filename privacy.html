Privacy Notice

Mbale Media Daily currently uses a static GitHub Pages website. GitHub Pages hosts the website and may process technical information as described in GitHub's own privacy documentation.

The current subscription form stores the email address in the visitor's browser using local storage. It does not currently send the address to Mbale Media's newsroom or to a newsletter provider.

Do not enter passwords, payment-card information or other sensitive information into the website forms.

When a real newsletter service is connected, this notice should be updated to identify that service and explain how subscriber data is handled.
