Access & privacy

Every sensitive feature requires user authorization.

  • No secret camera or microphone activation.
  • No password or keystroke collection.
  • No covert WhatsApp/SMS/call interception.
  • Files must be deliberately selected/uploaded by the owner.
  • Location sharing is visible and can be stopped.
  • Access can be revoked.

A production deployment should add server-side authentication, encrypted storage, HTTPS, access-control rules, audit logs, retention policies and secure backups.
