Privacy & access

SafeTrack does not secretly spy on people. This V2 prototype uses the browser Location API only after the user requests sharing and grants permission.

It does not read WhatsApp, SMS, passwords, keystrokes, camera or microphone, and it does not bypass device security.

For real multi-user live tracking, the next backend version should use authentication, HTTPS, encrypted location records, access logs, revocation, rate limits and automatic deletion/expiry.
