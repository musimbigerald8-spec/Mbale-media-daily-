# Mbale Media Daily Radio App

Installable PWA for Mbale Media Daily Radio. The app uses the station stream configured in the site and is designed for Android home-screen installation.

## Current features
- Live radio playback
- Play/pause and volume controls
- Install prompt on supported browsers
- News and TV navigation
- Mobile-first interface

## Important
Listener counts and now-playing metadata should only be displayed once a real provider API/feed is connected; the app does not fabricate these values.
